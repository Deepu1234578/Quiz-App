# Quiz-App
A web-based quiz management system for East West Polytechnic. Includes separate Teacher and Student portals for creating, taking, and reporting on quizzes, plus an Admin login. Built with vanilla HTML, CSS, and JavaScript — no framework, no backend, uses localStorage for data.

# Quiz App – East West Polytechnic

A simple web-based quiz management system built for East West Polytechnic, 
designed to let teachers create and manage quizzes while students take 
them and view their results.

## Features
- 🏠 College landing page with course/campus info
- 🔑 Admin/Teacher login
- 👩‍🏫 Teacher portal to create and manage quizzes by course
- 🧑‍🎓 Student portal to register (name, registration number, semester) and attempt quizzes
- 📝 Quiz-taking interface with rules and timed tests
- 📊 Report/result page to view scores after submission

## Tech Stack
- HTML5, CSS3, JavaScript (vanilla, no frameworks)
- Client-side data storage using `localStorage`

## Project Structure
- `index.html` – Home page
- `login.html` – Admin login
- `Teacher.html` / `Teacher.js` / `Teacher.css` – Teacher dashboard
- `Student.html` / `Student.js` / `Student.css` – Student registration
- `Quiz.html` / `Quiz.js` / `Quiz.css` – Quiz-taking screen
- `test.html` / `test.js` / `test.css` – Test/quiz logic
- `Report.html` / `Report.css` – Results/report view
- `result.html` / `result.css` – Result display
